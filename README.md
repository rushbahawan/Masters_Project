## Overview

This project investigates whether gut microbiome and clinical data can be used to classify depression in patients with Parkinson's disease (PD).

Depression is a common comorbidity in Parkinson's disease, but identifying it can be challenging because several depressive symptoms overlap with symptoms of PD. The gut-brain axis provides a biological motivation for investigating whether gut microbiome composition may contain information associated with depression.

The project uses machine learning to compare three types of information:

1. **Gut microbiome species abundance**
2. **Metabolic pathway abundance**
3. **Clinical and demographic metadata**

Five supervised machine learning models are evaluated across 12 experiments:

- Logistic Regression with LASSO
- Random Forest
- Support Vector Machine (SVM)
- XGBoost
- Multilayer Perceptron (MLP)

The models are evaluated primarily using ROC-AUC, with additional Precision-Recall analysis, bootstrap model comparison, feature importance analysis and statistical testing.

---

## Research Question

> **Can gut microbiome features be used to classify depression in patients with Parkinson's disease, and how does their predictive performance compare with clinical metadata and metabolic pathway features?**

The project also investigates whether a microbiome-based depression signal learned from Parkinson's patients generalises to healthy controls.

---

## Dataset

The project uses the publicly available dataset from:

**Wallen et al. (2022)**

The dataset contains:

- **724 subjects**
- **490 Parkinson's disease patients**
- **234 healthy controls**
- Clinical and demographic metadata
- Microbial species abundance data
- Metabolic pathway abundance data

The microbiome species and pathway tables used in this project were processed outputs generated by the original authors rather than raw FASTQ sequencing files.

### Depression Label

Depression status was operationalised using the dataset variable:

`Depression_anxiety_mood_med`

Samples were assigned:

- `Y` → depression label = 1
- `N` → depression label = 0

Therefore, the target should be interpreted as a **medication-based proxy for depression-related treatment**, rather than a clinically validated depression diagnosis.
